Getting started
1. Connect the microphones to your Mac. Pair Bluetooth microphones in System Settings first.
2. Choose a microphone and input channel on each participant's card. Add or remove participants while stopped.
3. Turn on Input volume adjustment if needed. Set the volume while stopped, then recalibrate.
4. Select Start to check the input levels. Choose Calibrate, measure the background sound, then let each participant speak alone for five seconds near their own microphone.
5. Select an output device and turn on live audio output. Use headphones to reduce acoustic feedback.
6. Recording is optional. Choose a folder to save one processed WAV file per microphone.

If input cannot start, check microphone permission, device connection and channel assignments. Choose different physical inputs for different participants. After changing the microphone placement, format or gain, recalibrate.

Bluetooth audio quality, available formats and latency depend on the device. Wakarukun Mixer does not guarantee complete removal of other voices in every room.
