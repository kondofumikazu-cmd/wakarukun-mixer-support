Getting started
1. Connect the microphones to your Mac. Pair Bluetooth microphones in System Settings first.
2. Choose a microphone and input channel on each participant's card. Add or remove participants while stopped.
3. Turn on Input volume adjustment if needed. Set the volume while stopped, then recalibrate.
4. Select Start to check the input levels. Choose Calibrate, measure the background sound, then let each participant speak alone for five seconds near their own microphone.
5. Select an output device and turn on live audio output. Use headphones to reduce acoustic feedback.
6. Recording is optional. Choose a folder to save one processed WAV file per microphone.

If input cannot start, check microphone permission, device connection and channel assignments. Choose different physical inputs for different participants. After changing the microphone placement, format or gain, recalibrate.

Bluetooth audio quality, available formats and latency depend on the device. Wakarukun Mixer does not guarantee complete removal of other voices in every room.

iPad / iPadOS 26.2+

Wakarukun Mixer adjusts microphone inputs on iPad and displays speaker-labelled captions for meetings and talks.

Configure one to eight participants. For multiple microphones, use one USB audio interface with multiple input channels and assign each channel to a participant. On iPadOS 26.2 or later, dual-route input can also combine the built-in microphone with a compatible input/output accessory. Independent Bluetooth or USB devices cannot be freely aggregated. Available inputs and audio formats depend on the iPad and connected hardware.

Calibrate by measuring background sound, then each participant in turn, to reduce sound bleeding into other microphones. Two or more inputs with sufficient measurements can use source separation; insufficient measurements use basic reduction. Recalibrate after changing placement or input gain. Complete removal is not guaranteed. Adjust input volume, mute and priority, with optional live output and WAV recording. Recordings appear in the app's Recordings folder in Files.

Apple on-device speech recognition displays captions in colour-coded participant columns. The latest caption stays visible, and full-screen display supports meeting and talk projection. Save captions with a title and speaker names locally on iPad, then read or delete them. Unsaved captions do not remain after quitting. Recognition accuracy, available languages and simultaneous recognition inputs depend on the device and Apple speech recognition. Recognition and microphone attribution may be incorrect. Language assets may need downloading initially.

Audio processing and caption generation run on-device. The developer does not receive audio or transcripts. No account is required. Microphone permission is required. Input stops when the app goes into the background. Headphones are recommended for live output. Shared interface text supports 50 languages and regions; iPad-specific connection guidance is available in Japanese and English.
