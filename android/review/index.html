KF transcription mixer: background microphone input

Google Play review demonstration for Android 1.0.0 (3), package jp.fumifumi.WakarukunMixer.

  1. Open Settings (設定), then Audio (音声), and select external speech recognition for this demonstration.
  2. Tap Start (開始) in the visible app. The microphone foreground service starts after this user action.
  3. Press Home. Microphone capture continues, with the persistent notification “マイクを使用しています” (Using the microphone).
  4. Tap Stop (停止) in that notification. Capture and the foreground service stop. The app returns to its Start state.

This screen recording uses an Android emulator with host microphone input disabled. It demonstrates the service controls and notification, rather than speech recognition accuracy. No personal audio, account details, or real conversation is included. The default on-device recognition setting is restored at the end.
