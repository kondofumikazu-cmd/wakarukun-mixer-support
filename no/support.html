Støtte

Velg en mikrofon og inngangskanal for hver deltaker. Start opptak for å se inngangsnivåer. For flere uavhengige mikrofoner, mål bakgrunnsstøy og la hver deltaker snakke alene nær sin mikrofon i fem sekunder for å kalibrere. Kalibrer på nytt etter å ha endret plassering eller forsterkning. Bruk hodetelefoner for direkte lydutgang.

Aktiver undertekster og velg det talte språket. Administrer brukerordbøker på første skjerm og velg en ordbok for hver deltaker. Bryteren for leseguide styrer furigana og andre støttede uttaleveiledninger. Apple Translation krever macOS 15 eller senere.

Lagre bildetekster med en tittel, og åpne dem deretter fra lagret historikk. Valgfri iCloud synkronisering krever samme Apple Account og iCloud Drive på enhetene dine. Bruk appens synkroniseringskontroller for å aktivere synkronisering eller synkroniser manuelt. Lokal bruk forblir tilgjengelig når synkronisering er avslått eller ikke tilgjengelig. Sjekk mikrofontillatelse og internettforbindelsen hvis gjenkjenning ikke kan starte.

Del bildetekster via QR eller lenke i appen eller en nettleser. Bildetekster, tilgjengelige oversettelser, talernavn og titler er ende-til-ende kryptert på enheten din før Cloudflare videresender dem. Dekrypteringsnøkler sendes ikke til reléet. Forhåndseksisterende lagrede historier sendes ikke. Nettleservisningen leveres av GitHub Pages. Økter varer maksimalt åtte timer; relédata slettes ved stopp, utløp eller terminering etter en sendeavbrudd. Leverandører behandler tilkoblingsinformasjon som IP-adresser. Lenkeinnehavere kan lese og lagre kopier som ikke kan tilbakekalles. Gjenutsted eldre QR-koder og oppdater både sende- og se-appene. Støttede enheter i samme QR-rom videresender også kryptert lyd fra kalibrerte mikrofoner over internett for å redusere duplikatgjenkjenning. Sammenligningslyd lagres ikke eller sendes til enheter som kun kan se. Wi-Fi eller mobildata brukes.

På støttede enheter kan Apple Intelligence oppsummere lagrede undertekster på enheten. Et kompatibelt operativsystem og språk samt aktivert Apple Intelligence er påkrevd. Sjekk genererte resultater mot originalen.

Del lagrede undertekster som .fumicap-filer via AirDrop, Mail eller andre systemdelingsdestinasjoner. Filene bevarer titler, originaler, oversettelser, talere, tider og leseveiledninger, uten lyd eller hele ordboken. Forhåndsvis mottatte filer og lag uavhengige historikker uten å endre kilden. Disse filene er ikke kryptert av denne appen; del kun med pålitelige mottakere.

iPhone / iPad · iOS / iPadOS 26.2+

KF transkripsjonsmikser gjør den innebygde mikrofonen på iPhone/iPad til bildetekster for møter og samtaler. Velg et språk og trykk på Start.

Juster bildetekststørrelsen fra 100 % til 200 %, vis leseveiledninger og trykk på originaler for å redigere. Apple Translation viser oversettelser etter fullførte setninger mens tidligere oversettelser er synlige. Roter 180 grader for en annen person; støttede oversettelsesspråkpar kan byttes.

Del bildetekster med QR/lenke i appen eller nettleseren. Forbered og tittel en QR før en hendelse og start den senere fra QR-historikken. Seere kan ikke redigere kilden og kan endre sine egne leseveiledninger og tekststørrelse.

Bildetekstinnhold er ende-til-ende kryptert på enheten før Cloudflare videresender det; dekrypteringsnøkler og tidligere lagrede historikker sendes ikke. Nettleservisningen bruker GitHub Pages. Leverandører kan se tilkoblingsmetadata som IP-adresser. Økter varer maksimalt åtte timer; relay-data slettes ved Stopp, utløp eller avbrudd fra utgiver. Lenkeenheter kan lagre kopier som ikke kan tilbakekalles. Gjenta eldre QR-koder og oppdater begge native apper. Støttede enheter i samme QR-rom videresender også kryptert lyd fra kalibrerte mikrofoner over internett for å redusere duplisert gjenkjenning. Sammenligningslyd lagres ikke eller sendes til enheter som kun kan se. Wi-Fi eller mobildata brukes.

Lagre mottatte bildetekster fra øktens begynnelse, inkludert senere rettelser. Catch-up trenger en aktiv utgiver; bildetekster som ikke er mottatt før en frakoblet økt avsluttes, kan ikke gjenopprettes.

Rediger lagrede titler/originaler, oppdater oversettelser eller slett historier. iCloud Drive-synkronisering for lagrede bildetekster og ordbøker er på som standard og kan slås av; bruke samme Apple-konto. Lokal sparing er fortsatt tilgjengelig. Støttede enheter kan lage lagrede bildetekstsammendrag på enheten med Apple Intelligence. Et kompatibelt OS/språk og aktivert Apple Intelligence kreves; sjekk genererte resultater.

Del lagrede bildetekster som .fumicap-filer via AirDrop, Mail eller andre systemdelingsdestinasjoner. Filer beholder titler, originaler, oversettelser, høyttalere, tider og leseveiledninger, uten lyd eller hele ordboken. Forhåndsvis mottatte filer og lagre uavhengige historier uten å endre kilden. Disse filene er ikke kryptert av denne appen; dele kun med pålitelige mottakere.

Apples nettverksgjenkjenning foretrekkes som standard og kan sende lyd/ordforråd til Apple med tillatelse. Hvis den ikke er tilgjengelig, brukes forberedt gjenkjenning på enheten. Eksplisitt modus på enheten bytter aldri stille til ekstern gjenkjenning. Last ned språk på forhånd; gjenkjennelse og oversettelse kan være feil.

Støttede innebygde mikrofoner tilbyr smal/bred pickup. Lytt gjennom støttede høyttalere, Bluetooth eller kablede utganger, og fortsett aktiv transkripsjon i bakgrunnen. Det er ingen annonser, sporing, analyser eller appkontoer. Grensesnittet støtter 50 språk/regioner.
